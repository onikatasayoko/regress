# 回归分析工具

一个用于实验数据拟合和绘图的单页工具。粘贴 `x y` 数据，选择拟合模型，就能查看方程和拟合优度，并将图表保存为 SVG 或 PNG。

页面没有后端，也没有第三方 JavaScript 依赖。数据计算在浏览器中完成，不会发送到服务器。为了恢复上次的操作，输入内容会保存在当前浏览器的本地存储中；超过 120,000 个字符的数据文本不会被保存。

## 支持的模型

- 线性：`y = ax + b`
- 二次：`y = ax² + bx + c`
- 指数：`y = a·e^(bx)`，要求所有 `y > 0`
- 幂函数：`y = a·x^b`，要求所有 `x > 0` 且 `y > 0`
- 对数：`y = a·ln(x) + b`，要求所有 `x > 0`

图表包含数据点和拟合曲线。坐标轴名称、单位和刻度间隔可以自行设置。线性拟合会显示 Pearson 相关系数 `R`；所有模型都会显示决定系数 `R²` 和数据点数量。数据点较多时，图上会抽样显示，拟合仍使用全部有效数据。

## 使用方法

每行输入一组数据，两个数分别为 `x` 和 `y`。可用空格、逗号或 Tab 分隔，以 `#` 开头的行会被忽略：

```text
1  2.1
2  3.9
3  6.2
4  7.8
5  10.1
6  12.4
```

点击“计算并绘图”查看结果。快捷键：`Ctrl+Enter` 计算、`Ctrl+S` 导出 SVG、`Ctrl+E` 导出 2× PNG。高清 PNG 可选择 2×、4×、6× 或 8×。

## 本地运行

下载 `index.html`，用浏览器打开即可，不需要安装依赖或启动服务器。

## 发布到 GitHub Pages

1. 将 `index.html` 放在仓库根目录。
2. 进入 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)` 目录，保存设置。
5. 等待发布完成后，在 Pages 页面打开提供的网址。

## 注意

指数、幂函数和对数拟合通过变量变换进行最小二乘拟合。异常值、重复的自变量和数值条件较差的数据都可能影响结果；使用时应同时检查散点图和实验背景，不建议只凭 `R²` 判断模型是否合理。
