# 回归分析工具（纯前端静态版）

这是从原 Go 版本改造而来的纯前端版本：不需要服务器、Go 后端、数据库或第三方 JavaScript 库。所有数据解析、回归计算、SVG 绘图和 PNG 导出均在用户浏览器中完成。

## 功能

- 线性、二次、指数、幂函数和对数拟合
- 自动生成散点图和拟合曲线
- 显示拟合方程、线性模型 Pearson R、决定系数 R² 和样本点数 n
- 自定义坐标轴名称、单位、刻度间隔
- 导出 SVG、2× PNG 和可选倍率的高清 PNG
- 浏览器本地保存表单设置
- 输入数据不会发到服务器

## 免费发布到 GitHub Pages

1. 解压项目，将 `index.html` 放到 GitHub 仓库根目录。
2. 把仓库设为 Public（如需给免费子域名审核方展示项目）。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 选择 **Deploy from a branch**。
5. Branch 选择 `main`，文件夹选择 `/ (root)`，点击 **Save**。
6. 等待 GitHub Pages 部署完成，按页面给出的 `https://用户名.github.io/仓库名/` 地址访问。

也可把单个 `index.html` 上传到 Cloudflare Pages 的 Direct Upload（静态文件部署）中。无需设置构建命令。

## 使用说明

每行输入两个数 `x y`，可用空格、逗号或 Tab 分隔；以 `#` 开头的行按注释处理。指数拟合要求所有 y 大于 0；幂函数拟合要求所有 x、y 均大于 0；对数拟合要求所有 x 大于 0。最多处理 200,000 个数据点，图中会在点数较大时自动抽样显示。

## 数值稳定性说明

线性和变换回归使用缩放后的自变量与中心化统计量，二次拟合先将 x 中心化和缩放后再解 3×3 方程，避免直接在原始大尺度 x 上构造高次幂带来的明显精度损失。对于极端值、重复 x 或高度病态的数据，数值拟合仍可能有局限；结果应结合实验背景检查。
